
\assignmenttitle
    {LAB ASSIGNMENT - 01}
    {WINDOWS INSTALLATION}

\aim{To install the Windows operating system on a computer system.}

\appr{Computer System, USB Drive}

\sectionlabel{Theory:}
Installation of Windows operating system involves preparing a bootable drive, booting the computer from the drive, and configuring the operating system. Once installed, the operating system provides a platform for running applications and performing various computing tasks.

\sectionlabel{Procedure:}

\begin{itemize}
    \item Create a bootable USB drive using the Windows ISO file.
    \item Insert the bootable USB into the computer.
    \item Restart the computer and enter the BIOS boot menu.
    \item Set the USB drive as the first boot device.
    \item Save the settings and restart the system.
    \item Select the language, time, and keyboard preferences, then click Install Now.
    \item Enter the product key or choose I don't have a product key.
    \item Select the desired Windows edition and accept the license terms.
    \item Choose Custom: Install Windows only and select the target drive or partition.
    \item Wait for the installation to complete and allow the system to restart.
    \item Complete the initial setup by creating a user account and configuring basic settings.
    \item Verify that Windows has been installed successfully and the desktop loads correctly.
\end{itemize}

\sectionlabel{Learning Outcomes:}
\begin{itemize}
\item{Creating a bootable USB.}
\item{Booting the computer from the USB.}
\item{Installing the Windows operating system on the system.}
\end{itemize}


\concl{The Windows operating system was installed successfully on the computer system. The installation process completed without errors and the system booted into Windows successfully.}
